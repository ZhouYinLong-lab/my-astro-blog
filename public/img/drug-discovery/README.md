# 药物发现文章配图

本目录的四张图均为仓库内制作的技术示意图，不是 AI 生成图片，也不是论文原图。原始 SVG 保存在 `illustrations/how-drug-molecules-are-found/source/`，发布资源使用转换后的 WebP。

- `01-drug-discovery-funnel.webp`：药物发现逐层筛选示意图。
- `02-azt-chain-termination.webp`：AZT-三磷酸造成 DNA 链终止示意图。
- `03-structure-based-design.webp`：结构导向设计中的蛋白口袋与配体示意图。
- `04-virtual-screening-to-wet-lab.webp`：虚拟筛选连接到微孔板湿实验示意图，数字来自 Lyu 等，2019。
