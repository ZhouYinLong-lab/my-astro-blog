# 药物发现文章配图

三张技术图的 SVG 源文件位于 `illustrations/how-drug-molecules-are-found/source/`。发布资源使用 WebP。

- `01-drug-discovery-funnel.webp`：根据 [FDA 的药物发现与开发说明](https://www.fda.gov/patients/drug-development-process/step-1-discovery-and-development) 绘制的早期筛选流程。
- `02-azt-chain-termination.webp`：参考 [St. Clair 等，1987](https://pmc.ncbi.nlm.nih.gov/articles/PMC175837/) 绘制的 AZT 链终止对照图。
- `03-structure-based-design.webp`：来自 [RCSB PDB 1OHR](https://www.rcsb.org/structure/1OHR) 的[组装体原图](https://cdn.rcsb.org/images/structures/pdb/1ohr_assembly-1.jpeg)，转换为 WebP。对应论文为 [Kaldor 等，1997](https://doi.org/10.1021/jm9704098)。
- `04-virtual-screening-to-wet-lab.webp`：按 [Lyu 等，2019](https://doi.org/10.1038/s41586-019-0917-9) 报告的 D₄ 受体筛选数据绘制的流程图。
